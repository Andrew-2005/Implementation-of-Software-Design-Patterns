# Список завдань за шаблоном MVC

Навчальний застосунок на Python і Tkinter. У ньому можна додати завдання, змінити його статус і видалити його. Завдання зберігаються в пам’яті до закриття вікна.

## Запуск

Потрібен Python 3.11 або новіший із Tkinter. Запустіть із папки проєкту.

```powershell
python main.py
```

## Ролі MVC

- **Model** (`model.py`) зберігає завдання, перевіряє їхні назви та змінює стан.
- **View** (`view.py`) відображає поля введення, кнопки й таблицю та передає дії користувача контролеру.
- **Controller** (`controller.py`) обробляє дії користувача, викликає методи моделі й передає оновлений список до View.
- `main.py` створює ці три компоненти та запускає цикл подій Tkinter.

Коли користувач натискає «Додати», контролер читає назву з View і передає її моделі. Якщо назва порожня, контролер передає повідомлення до View. Після успішного додавання View показує оновлений список і виділяє нове завдання.
